# RemoteInspector 独立桌面端

WPF + 纯 .NET 核心，运行时不需要 Unity Editor、Unity DLL 或 Unity 工程目录。保持现有游戏 Runtime 的 TCP 协议，默认端口 9555。

## 快速使用

1. 打开 `artifacts/portable-win-x64/RemoteInspector.exe`。这是 Windows x64 自包含发布，已包含 .NET 运行时；分发时复制整个文件夹。语言资源仅保留简体中文（zh-Hans）。
2. 点击“启动监听”。如果原 Unity Remote Inspector 正在监听 9555，先在旧工具中停止监听，或给新工具更换端口。
3. 游戏中执行 `/connect <运行本程序的电脑IP> 9555`，同机游戏可以使用 `127.0.0.1`。跨设备连接需要网络可达、Windows 防火墙允许对应端口。
4. 客户端握手成功后自动刷新一次节点树；也可点击场景层级收藏按钮旁的“刷新节点树”。选择会话，点击节点获取详情，展开组件或材质组，从下拉框 / ▾ 常用值菜单选值，也可以手动输入。点击该行“应用”后写入，成功后自动重新读取远端值。
5. 程序不会自动连接设备或修改游戏。暂停、恢复、RPC、属性及文件操作只针对所选会话。

停止监听和关闭窗口可连续操作；应用会结束连接及未完成请求，释放监听端口后退出。重复点击关闭不会重复执行清理。

也可以只加载 `.bin` 快照离线查看，无需启动监听或连接游戏。

| 属性 | Unity Inspector 风格组件折叠、材质槽分层、刷新保持折叠状态；布尔勾选、向量分轴、枚举下拉、LayerMask 具名多选及常用值菜单 |

## 兼容范围与边界

- 游戏端代码来源：`G:/SuperMain/Client/Assets/ThirdPart/RemoteInspector`。2026-10-26 新增 Runtime 纹理可读标记、截图拾取及原尺寸纹理导出协议；旧 Editor 工具及旧命令保留。
- 原 README 的协议描述落后于代码：当前心跳超时是 30 秒，节点树使用二进制 v2 主路径；按实际代码适配。
- 纹理响应在现有 Runtime 中固定 `sequence=0`，独立端按连接隔离并串行请求纹理；纹理块与截图块按各自现有编码方式处理。
- DTO 保留原 public 字段名称；JSON 使用 System.Text.Json 的 IncludeFields。核心没有 WPF 或 Unity 程序集依赖。
- 现有 Runtime 只有节点树二进制编解码器，节点详情实际仍发 JSON。独立端不宣称支持缺失的二进制详情格式。
- 属性编辑服从现有 Runtime setter 的能力。不支持写回的 Unity 内置摘要字段、集合、对象引用及 Int64 等字段只读。真实类型保留在字段提示与协议中，不允许随意转换字段类型。
- 布尔值使用勾选框；可解析的枚举显示名称及实际整数值。向量与颜色提供分轴输入，数值、向量、颜色、Render Queue 提供 ▾ 常用值菜单，选择后仍需点击“应用”。材质详情首次查看默认折叠，刷新后保留用户的展开状态。
- 枚举数值来自附带的 `enum-values.json`，以元数据方式读取程序集常量后生成，运行时不需要这些程序集。附带字典包含当前本机工程及 Unity 2022.3.24f1 的 5148 个枚举定义。名称列表或当前具名值不匹配、同名类型存在冲突时回退到整数输入，不把下拉索引当枚举值。字典需要与目标游戏版本对应；Flags 组合值可保留和手动输入。
- Camera LayerMask 使用附带的 layers.json 显示 Default、UI、Player 等工程层名，支持多选、Nothing 和 Everything。导出保留 32 个槽位及空槽，包含第 31 位的有符号掩码；运行时不依赖 Unity 工程。
- 独立端已移除图片替换入口。原 Runtime 图像替换命令仍保留，兼容旧 Editor。
- 单个文件上传/下载上限 1 GiB；图片传输上限 64 MiB；会话纹理缓存总量上限 128 MiB，超限时清理缓存。文件大小上限不代表游戏端能够承受同等大小的内存分配。
- 现有 Runtime 上传只有一个槽位且没有取消命令。上传启动后取消、超时或失败会断开该会话，让 Runtime 释放上传状态及未完成文件；其他会话不受影响。
- 节点是否激活以 `activeInHierarchy` 为准，保持旧 Editor 的判断方式。节点区分“已激活”“自身未激活”“父级未激活”；筛选保留父级路径并标注“路径”，这些上下文节点不计入命中数。未激活节点仍可选中查看详情。悬停可查看两种激活标记和 InstanceID。
- 节点激活状态以最近一次采集为准；修改 GameObject 的 activeSelf 后自动重新采集整棵树，更新受父级影响的子节点。断线保留最后数据并显示过期提示。
- 完整快照采集按节点顺序读取详情，不等同于同一帧的原子快照。场景动态变化可能出现缺失对象；纹理只导出已预览并缓存的内容。快照保存选中节点和展开路径，加载时恢复对应层级。
- 当前沿用开发工具的明文 TCP 协议，没有新增认证或公网访问层。
- 已通过模拟 Runtime 联机及 WPF 渲染测试；尚未完成真实游戏包、手机设备、真实旧快照样本和实际超大场景的联调验收。

## 工程结构

```text
RemoteInspector.sln
src/
  RemoteInspector.Core/       net10.0；TCP、协议、DTO、会话、传输、快照
  RemoteInspector.Desktop/    net10.0-windows；WPF 窗口、属性控件、图片与图表
tests/
  RemoteInspector.SmokeTests/ 无外部测试库；协议、模拟联机、WPF 交互和渲染
tools/
  RemoteInspector.EnumCatalog/ 仅读取 DLL 元数据，导出枚举名称与实际值
config/
  enum-values.json           发布时复制到程序目录的枚举字典
  layers.json                从 TagManager.asset 只读导出的 32 个 Layer 槽位
scripts/
  Build.ps1                  构建、验证、自包含发布
artifacts/
  portable-win-x64/           可直接运行并分发的整个文件夹
  verification/              验证日志、兼容测试文件、界面截图
```

原协议和数据模型迁移为本工程内的独立副本，没有链接到 Unity 工程的编译文件。协议改动时，应同时核对两端命令号、JSON 字段和二进制版本；不要直接覆盖已移除 Unity 依赖的副本。

## 构建与验证

需要 Windows 和 .NET 10 SDK。`global.json` 固定当前验证用 SDK 10.0.301，允许同 feature band 后续补丁。

```powershell
Set-Location G:\SuperMain\RemoteInspector
.\scripts\Build.ps1
```

该脚本先构建 solution、执行验证，再发布 Windows x64 自包含程序。若需要更小的依赖框架版本，可使用 `-FrameworkDependent`，使用者需要安装 .NET 10 Desktop Runtime。

手动执行：

```powershell
$env:MSBuildEnableWorkloadResolver = 'false'
dotnet build RemoteInspector.sln -c Release
dotnet run --project tests/RemoteInspector.SmokeTests -c Release -- artifacts/verification
dotnet publish src/RemoteInspector.Desktop -c Release -r win-x64 --self-contained true -o artifacts/portable-win-x64
```

禁用 Workload Resolver 是为了绕过本机 .NET SDK 的 MSI workload 信息异常；本项目没有工作负载依赖。核心和桌面端都没有外部 NuGet 库依赖。自包含发布第一次可能需要联网获取微软运行时包。

## 验证及真实设备验收

自动验证包括独立构造的报文和旧快照格式、多客户端使用相同 InstanceID 的隔离、二进制超过 65535 节点、实际 TCP 属性写入后回读、超时及取消、纹理序列号 0、文件分块及部分下载清理、WPF 点击操作和页面离屏渲染。

真实游戏验收建议按以下顺序进行：

1. PC 游戏连接，获取二进制节点树、展开层级和搜索节点。
2. 修改 Transform、脚本标量、Camera / BoxCollider 支持字段及材质属性，确认游戏内生效并刷新回读。
3. 抓图、预览纹理、浏览/上传/下载测试文件、调用实际注册 RPC。
4. 加载由旧 Unity Editor 导出的快照，并用旧工具回读新程序导出的快照。
5. 两个设备切换会话、断线重连、采集完整快照、检查大场景下的响应和内存。

上方同时显示节点树与 Inspector，下方同时显示日志等诊断工具与文件浏览器。分隔条可拖动，退出后保存宽度比例和底部高度；日志选中后显示完整内容及堆栈。

每次启动默认监听端口为 9555，不恢复先前的测试或临时端口；可在启动监听前手动修改。布局与 RPC 模板配置保存在 `%LOCALAPPDATA%/SuperMain/RemoteInspector/settings.json`。

## 更新枚举下拉字典

当目标游戏程序集更新时，可只读扫描与该游戏版本对应的 Managed DLL，重新生成字典后重新发布：

```powershell
$env:MSBuildEnableWorkloadResolver = 'false'
dotnet run --project tools/RemoteInspector.EnumCatalog -c Release -- config/enum-values.json G:/SuperMain/Client/Library/ScriptAssemblies G:/UnityHub/Unity2022.3.24f1/Editor/Data/Managed/UnityEngine
.\scripts\Build.ps1
```

也可以使用游戏构建产物的 Managed 目录作为输入。工具不加载、不执行这些程序集，不修改 Unity 工程。生成后只分发 JSON；独立程序不会在运行时连接 Unity 或访问上述目录。缺少字典时布尔勾选和常用值菜单仍可使用，枚举回退到原有数值输入。

## 更新工程 Layer 名称

只读导出工程层定义，随后重新发布：

dotnet run --project tools/RemoteInspector.EnumCatalog -c Release -- --layers G:/SuperMain/Client/ProjectSettings/TagManager.asset config/layers.json

## 查 Bug 工作流

- 节点区提供后退、前进与收藏列表；Inspector 显示完整路径、InstanceID 和激活状态，可复制路径。历史和收藏按会话隔离，保留在本次运行中，不跨游戏重启复用 InstanceID。
- 日志取消“跟随最新”后暂停自动滚动，接收仍继续；“回到最新”恢复跟随。右键可复制完整消息与堆栈，或以当前消息筛选。现有日志协议没有可靠对象关联字段，因此不猜测关联节点。
- 展开“对比 / 监视 / 自动刷新”：记录当前节点基准后，可刷新详情并勾选“只看变化”。黄色行及“未应用”表示本地编辑；“还原未应用编辑”恢复最近读取值，不发送请求。基准包含当时显示的本地编辑，按会话、节点和完整字段身份隔离。
- 选中属性行后“固定所选属性”，在“动态监视 / 固定属性”页查看跨节点值及更新时间。手动“刷新监视值”会读取各节点详情，保持当前 Inspector 和未应用编辑。监视按会话隔离，仅本次运行保留。
- 可锁定 Inspector 对象，并选择 1/2/5 秒自动刷新。输入框编辑中或存在未应用值时暂停自动刷新；手动操作会取消在途自动刷新，避免旧响应覆盖操作结果。属性自动刷新只刷新当前 Inspector 对象；节点监听有独立的自动采样设置。
- 顶部提供默认、对象排查、日志排查、性能观察布局预设，拖动后的分隔比例仍保存到配置。
- RPC 可保存每个方法的参数模板，退出时随本机配置保存；选择模板仅填充参数，仍须点击执行。
- 文件区底部保留传输进度和结果；状态栏显示当前操作与耗时，可取消未完成请求。
- “保存现场”导出 ZIP：兼容离线快照 snapshot.bin、当前会话近期日志 logs.txt、FPS frames.json、采集信息 incident.json，以及存在时的最近图片 latest-image.png。仅打包已采集数据，不自动抓图或遍历整场景；解压后可直接加载 snapshot.bin。各数据不是同一帧的原子现场。

## 2026-10-26 图片、拾取与压缩日志

- 纹理项直接显示“可预览”按钮；Read/Write 未开启或不是可读 Texture2D 时按钮保留并置灰，悬停可查看原因。旧 Runtime 未提供标记时置灰并提示更新；离线快照存在缓存纹理时允许预览。
- 点击行内按钮打开独立纹理窗口，可导出预览 PNG；更新 Runtime 后还可“导出原尺寸 PNG”，保留原尺寸与透明度。原尺寸导出限制 1600 万像素、编码结果 64 MiB，编码不支持的格式会报告错误。旧预览协议仍为最大 256 像素 JPG。
- “图片”页抓取当前游戏画面，勾选“点击截图定位 UI / 物体”后点击图像。坐标扣除缩放留白并转换为 Unity 左下角原点；远端按点击时的相机和 UI 进行检测，不发送点击事件。屏幕横竖比例已变化时要求重抓截图。
- 相交结果显示在节点树上方的“截图相交节点”列表，点击定位原节点。结果优先 uGUI，再按相机深度与 NGUI 控件深度/物理距离列出，最多 64 个；物理相机每次最多检测 256 个 3D 碰撞。没有碰撞体的普通场景网格不参与物理拾取，uGUI 依赖 GraphicRaycaster。树中缺失的命中对象会先刷新节点树，保持远端原顺序。
- 双击远端 .logcompr 文件自动切换到文件区的“压缩日志”Tab：下载后使用随程序附带的 BqLog_LogDecoder.exe 解码，边解码边显示。可开启每 2 秒重新下载解码，文件持续增长时更新预览；切换会话或关闭程序会取消下载并终止解码子进程。窗口显示末尾最多 2 Mi 字符，导出包含完整解码文本，单次解码上限 128 Mi 字符。
- 解码器位于 tools/LogDecoder，附带 Apache 2.0 许可；使用 stdout，不依赖外部构建工具目录。该版本正常 EOF 返回码是 1，已兼容处理。
- 新增协议：0x0092 截图拾取请求、0x0093 命中响应、0x0094 原尺寸纹理请求（响应沿用 TEXTURE_RESPONSE）。截图定位、Read/Write 标记及原尺寸导出需要重新构建包含新增 Runtime/Shared 的游戏包；旧命令 ID 和入口未改名、删除。

## 文件与压缩日志页签

远端文件区提供“远端文件 / 压缩日志”两个 Tab。双击 .logcompr 后切到压缩日志；切回文件页仍保留原目录。打开另一份日志会取消上一份的读取任务。

日志页可输入关键字查找（忽略大小写），提供上一处/下一处、匹配计数和清除；Enter 下一处，Shift+Enter 上一处，Esc 清空。查找范围是当前显示的末尾最多 2 Mi 字符，匹配处会选中并滚动定位。刷新重新下载远端文件并解码，“导出解码文本”保存完整文本。定时刷新可选，切换 Tab 不丢失日志内容。

## 图片缩放与拾取

图片页提供 5%—400% 缩放滑条、适应窗口和原始大小（100%），也可 Ctrl+滚轮缩放。新截图默认适应窗口，放大后使用横向/纵向滚动条查看局部；手动调整缩放后不会被窗口尺寸变化自动覆盖，再点适应窗口恢复自动适配。

拾取按图片自身的显示尺寸转换归一化坐标，缩放、居中和滚动不改变目标位置，导出仍保存原始图片数据，不导出缩放后的屏幕显示。

## 组件状态与节点动态监听

Inspector 取消独立的无效“图片与纹理”摘要分组，保留序列化字段和材质中的有效纹理预览。组件标题不再显示 [0]；同类型重复组件从第二个起显示“第 2 个”等提示，内部仍使用原组件索引写回。标题标注已启用、组件已禁用或节点未激活；禁用组件和参数置灰，Enabled / Active 开关保持清楚，参数仍允许编辑。

右键场景树节点可“加入监听 / 移除监听”。动态监视分为“节点与组件”和“固定属性”两个页签：

- 默认每 2 秒采样当前会话的监听节点，可改为 1/5 秒、关闭自动监听或立即采样。
- 首次采样建立基准；后续列表记录名称、路径、激活、Layer/Tag、子节点，以及组件增删、启用状态、已采集参数的前后值。
- 双击监听节点或变化记录可反向定位场景树；确认销毁后自动移除监听，保留销毁记录并清空失效 Inspector。
- 断线、超时或采样失败保留监听，不当作节点销毁。监听按会话隔离，仅本次运行保留；单会话最多 50 个节点，保留最近 1000 条变化。
- 采样不是逐帧事件订阅，间隔内的瞬时变化可能遗漏；只有远端已公开采集的数据可以比较。为降低负载，只采样当前选中的实时会话，手动请求或节点详情读取期间会让出采样机会。
- 游戏端 GET_NODE_TREE 显式请求现会使缓存失效并重新采集。需要更新包含此次 Runtime 修复的游戏包，才能可靠观察组件增删和节点销毁；旧游戏包的缓存可能导致检测延迟。

## RPC 紧凑面板

RPC 按“函数选择 / 方法与参数 / 模板和执行 / 结果”排列。点击“选择函数”打开可搜索弹层，支持按名称、签名及说明过滤和刷新列表；选择后填入方法并显示签名，不自动执行。也支持手动输入方法。

参数必须是 JSON 数组，无参数填写 []。格式错误会就地提示并禁用执行；Ctrl+Enter 可执行当前调用。执行中禁止重复提交，返回内容格式化显示，可展开、收起及复制。参数模板下拉和保存按钮位于编辑区下方，仍沿用已有本机模板配置。

重载 IFix / 重载 ILRuntime 常驻顶部，直接一键调用。热更新反馈单独显示，不覆盖正在编辑的方法、参数和普通 RPC 的返回结果。函数选择与热更新按钮在窄面板内自动换行。

## 场景树位置、路径定位与收藏

刷新场景树、切换激活筛选时，按可见节点与屏幕内偏移恢复浏览位置；优先保持当前可见选中节点的位置。目标被筛选隐藏或已销毁时回退到原滚动偏移，树边界处由可用滚动范围限制。根节点及子节点仍保持远端顺序。

Inspector 顶部“定位节点”清除树筛选并展开关联节点，不重新读取详情，保留正在编辑的属性。复制完整路径粘贴到场景树搜索框，按 Enter 或点击搜索可直接定位唯一同路径节点；重名路径保留搜索结果供手动选择。

节点右键支持收藏/移除收藏，Inspector 也可切换收藏。顶部“收藏节点”列表按远端顺序列出完整路径及 ID，每项提供定位和移除，列表底部可清空此会话收藏。收藏按会话隔离，在本次运行中保留，避免游戏重启后 InstanceID 复用导致关联错误。
